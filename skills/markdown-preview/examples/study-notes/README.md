# 从读懂到记住：间隔复习

读完一段觉得熟悉，和合上笔记还能讲出来，是两件不同的事。这组三页用同一个例子：记住「主动回忆」和「间隔复习」的区别。

## 01 · 先分清两个动作

主动回忆回答的是「怎么复习」：先不看笔记，用自己的话尝试作答。间隔复习回答的是「什么时候复习」：把多次回忆分散在不同日期。

如果一开始想不起来，可以先写出半句话，再看原文核对。核对后立刻合上笔记，说一遍完整的解释。
