\section{Results}
We fit the intermediate regime using the same estimator at each system size.
The finite-size correction is parameterized by a single leading coefficient:
\begin{equation}
  E(L) = E_{\infty} + \frac{a}{L^2}.
  \label{eq:scaling}
\end{equation}
We report the sensitivity of the fitted limit to the smallest size included
in the fit. The estimator is held fixed across those fits.
