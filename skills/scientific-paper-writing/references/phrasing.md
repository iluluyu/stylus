# Wording (Phrasebank approach) — codes W1–W6

**Core idea:** most academic sentences perform a recognizable function. Pick a standard, content-neutral frame for that function, then fill it with the science. Prefer the shortest frame; physics letters reward directness.

---

## W1 — Concision; no empty openers

| Wordy                                              | Concise              |
|----------------------------------------------------|----------------------|
| in order to                                        | to                   |
| due to the fact that                               | because              |
| a large number of                                  | many                 |
| has the ability to / is able to                    | can                  |
| make use of / utilize                              | use                  |
| in the case of                                     | for                  |
| a total of N                                       | N                    |
| is shown to be                                     | is                   |
| at the present time                                | now / currently      |
| in the absence of                                  | without              |
| with the increase of N                             | as N increases       |

Empty openers — delete, then start with the content:

- *It is well known that ...* → add a reference instead
- *It is worth noting that ... / It should be noted that ...*
- *It can be seen from Fig. 2 that ...* → *Figure 2 shows that ...*
- *In this paper, we ...* at the start of every paragraph

- Self-check: *Can I delete words without losing meaning?*

## W2 — Standard frame for the sentence's function

| Function              | Example frames                                                                                         |
|-----------------------|--------------------------------------------------------------------------------------------------------|
| Establish importance  | X is a central challenge for ... / X underpins ...                                                     |
| Summarize prior work  | Previous studies have shown that ... [refs] / X has been realized on superconducting [refs] and trapped-ion [refs] platforms. |
| Identify the gap      | However, these approaches require ... / It remains unclear whether ... / No ... has yet ...            |
| State the contribution| Here we show that ... / In this Letter, we demonstrate ... / We introduce ..., which ...                |
| Describe methods      | We prepare ... by ... / To quantify ..., we compute ... / Following Ref. [n], we ...                   |
| Report results        | Figure 2(a) shows ... / The error rate decreases from X to Y as ... / We observe ...                   |
| Compare               | This agrees with the prediction of Eq. (3). / In contrast to ..., our scheme ... / ... outperforms ... by a factor of ... |
| State limitations     | The main limitation of this approach is ... / Our analysis assumes ..., which holds when ...          |
| Conclude / outlook    | We have demonstrated ... / A natural extension is ... / These results enable ...                      |

The Manchester Academic Phrasebank has many more frames by function. Some are wordy (written for all disciplines); compare with recent papers in the target journal and choose the shortest.

- Self-check: *What is this sentence's job? Does its frame make that job obvious?*

## W3 — One concept, one term

Use the same term for the same concept throughout. Do not vary synonyms for style. In scientific writing, a new word suggests a new thing.

- Inconsistent: *ansatz* (¶2) → *parametrized circuit* (¶4) → *variational form* (¶6), all meaning the same object.
- Fix: choose one term, define it at first use, and keep it.

The same applies to symbols (C1) and abbreviations (C5).

- Self-check: *Could the reader think two of my terms mean different things?*

## W4 — Calibrated hedging

Match the strength of the verb to the strength of the evidence.

| Evidence                                   | Verbs                                        |
|--------------------------------------------|----------------------------------------------|
| Direct measurement or proof                | show, demonstrate, prove (for proofs only)   |
| Strong but indirect                        | indicate, provide evidence that              |
| Plausible interpretation                   | suggest, is consistent with, we attribute ... to |
| Speculation                                | may, could, possibly                         |

- Do not hedge direct measurements (*the fidelity seems to be 99.7%* → *the fidelity is 99.7%*).
- Do not stack hedges (*may possibly suggest* → *suggests*).
- Do not overclaim interpretations (*proves that the speedup is quantum* → *indicates* unless there is a proof).

- Self-check: *Would a skeptical referee accept this verb for this evidence?*

## W5 — No hype

Avoid: *novel, unprecedented, groundbreaking, revolutionary, paradigm shift, remarkable, extremely, very, highly efficient* (without a number).

- Replace adjectives with numbers: *a highly efficient scheme* → *a scheme that halves the CNOT count*.
- "First" claims: mark `[CHECK: priority]` until the author confirms.
- Let the result carry the significance; referees discount self-praise.

- Self-check: *Is there a number or comparison that could replace this adjective?*

## W6 — Tense and voice

- **Present tense:** established facts, what figures show, what the paper claims (*Figure 2 shows*, *we show*, *Eq. (3) gives*).
- **Past tense:** specific procedures and observations (*we measured*, *we observed*, *the run lasted 12 h*).
- **Present perfect:** prior work with continuing relevance (*Previous studies have shown ...*).
- **Active voice with "we"** is standard in PRL and Nature. Use the passive when the agent is irrelevant, or when it puts the familiar entity in the topic position (S2).

- Self-check: *Is this a lasting claim (present) or a completed action (past)?*
