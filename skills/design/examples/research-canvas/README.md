# Native scientific canvas example

Open with `node ../../scripts/artifact.mjs open .` from this directory, or pass
this folder's path from elsewhere. Files under `project/` are the editable source.
The three nodes, two connectors and each label are separate native elements.
The symbols A, B, AB, k₁ and ΔG are illustrative, with no numerical data.
Arrows mean procedure order, not proof of causation or measured reaction rates.

Frame: 688×360 CSS px. Labels: 16px, note: 14px. Physical size and smallest
final type must be measured after export; no exact-mm output is promised.
Use Export in the bundled editor; do not open Main.dc.html directly as a page.
